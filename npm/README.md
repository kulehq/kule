# @kulehq/kule

Kule is a control room for AI agents that work on your folders. Agents do
the work in a sandboxed copy-on-write copy of the folder; a policy, and
you, decide what reaches the real folder, and every commit can be undone.

**This package does not install Kule.** It marks the name and points to
where Kule is:

- **Install:** the macOS app and the Linux `.deb`/`.rpm`, each with the
  `kule` command, are on the
  [GitHub releases](https://github.com/kulehq/kule/releases), with
  checksums and build provenance. Or build it from source:
  https://kulehq.github.io/kule/docs/getting-started/install
- **Documentation:** https://kulehq.github.io/kule/ (English and Turkish)
- **Source:** https://github.com/kulehq/kule

Each version of this package matches a Kule release; pre-releases are
under the `preview` dist-tag.
